Personal backup utility

SORA VPS Backup

A private disaster recovery utility for backing up the owner's SORA server to the owner's own Google Drive.

What this application does

SORA VPS Backup uses Rclone and Google OAuth to transfer encrypted backup archives from an owner-managed virtual private server (VPS) to Google Drive for disaster recovery.

  • Transfers existing encrypted backup files to the owner's Google Drive.
  • Checks uploaded files for integrity by reading them back.
  • Helps the owner recover their system after server loss or failure.

Limited Google Drive permissions

The application uses the drive.file OAuth scope, allowing access to Google Drive files created by or opened with the application. It is not intended to scan personal documents, emails, or unrelated Drive files.

Who uses it?

This is an owner-operated utility for personal infrastructure backup. It is not offered as a public backup service and does not have public user registration.

Privacy and contact

Read the Privacy Policy for details about Google Drive data access, local credential handling, retention, and revoking access. For inquiries, use the support email displayed on the application's Google OAuth consent screen.
